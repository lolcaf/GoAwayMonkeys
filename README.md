# Go Away Monkeys
Ever met a famous person or wanted to take a selfie with someone but there are too many little kids in the way of your photo? Now you can hide those monkeys and take a better picture with them! You can leave this mod active in the background, it wont bother you : )
## Controls
There is a new button on the LIV Camera called "Focus". Simply click the focus button on and select the player you want with the gun lib to focus and everyone else will be hidden.

There is no dependency!
